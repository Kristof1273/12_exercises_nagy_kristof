# PHP Testing Exercises

PHPUnit exercises: unit tests, data providers, test dependencies, TDD, stubs and mocks.

## Requirements

- PHP 8.2 or newer (CLI)

## Install PHPUnit (PHAR)

```bash
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
php phpunit.phar --version
```

## Run the tests

```bash
php phpunit.phar
```
